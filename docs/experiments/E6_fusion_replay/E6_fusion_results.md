# E6-T-FUS — 고정 입력 fusion replay

**실행일:** 2026-10-28  
**상태:** KF31–35의 저장 ROI replay 완료. 실제 정상 영역 음성 대조 및 독립 대응 검증은 `INSUFFICIENT_SUPPORT`; 원인 우세 판정은 보류.

## 질문과 사전 가설

첫 tracking fusion 입력이 최종 canonical map과 KF 간 대응 후보의 분리에 어느 정도 영향을 주는가? 사전 가설은 첫 입력이 고정된 후속 관측과 pose 아래에서 최종 map에 측정 가능한 영향을 준다는 것이다. 개선이나 성공의 수치 임계값은 설정하지 않았다. [실행 전 protocol](../../../configs/E6_fusion_replay/protocol.json)에 데이터, 개입, 고정 support와 지표를 기록했다.

## 방법과 재현

E3의 HKairport01 동일 실행에서 KF31–35의 초기 ROI와 23개 업데이트를 읽었다. 원본 가중 평균 `X'=(C X+C_in X_in)/(C+C_in)`, `C'=C+C_in`을 float32로 순서대로 재현했다. 개입군은 각 KF의 **첫 tracking 입력 하나만** 생략하고 나머지 캡처 입력과 상대 pose를 고정한다. 입력은 이미 원래 pose로 KF-local에 변환된 값이므로 네트워크 inference, tracking, backend를 다시 실행하지 않는다. 첫 입력 이후의 관측이 실제 개입 시스템에서도 동일할 것이라는 보장은 없다.

E2a의 세 쌍 후보를 E1 export가 존재하는 픽셀로 제한하고 두 실험군에서 동일한 pixel ID를 사용했다. 각 쌍의 E1 source 후보에서 PCA 법선을 구해 +world Z 쪽으로 부호를 고정했다. KF-local은 각 KF 카메라 좌표, world는 `s R X + t`이고 quaternion 순서는 xyzw, scale은 임의 단위다. Camera Z, 초기 점에서의 단위 ray, world Z와 고정 법선은 서로 다르다. KF36 backend pre/post 및 KF52 post pose를 같은 map들에 적용했다. KF36 이후 map은 실제로 freeze되어 있으며 변경 map에 대한 pose는 frozen counterfactual이다.

초기 실행에서 양쪽 KF의 첫 입력을 동시에 제외한 결과를 확인한 뒤, 개별 기여를 구별하기 위해 **사후 탐색으로** 각 쌍의 A만, B만, 양쪽 모두 제외한 열을 추가했다. 따라서 개별 쌍 결과는 사전 등록된 별도의 확증 검정이 아니다. 두 KF를 동시에 제외하는 열은 단일 입력 개입이 아니라 참고용이다.

```bash
MPLCONFIGDIR=/tmp/mpl-e6 thirdparty/mast3r-env/bin/python scripts/E6_fusion_replay/replay.py <새_run_id>
```

`run_id`를 생략하면 `frozen_replay_final`을 사용하고, 기존 디렉터리는 덮어쓰지 않는다. 입력 및 실행 스크립트와 protocol SHA-256은 결과의 `manifest.json`에 보존했다. 첫 실행과 사후 확장 실행도 각각 `frozen_replay`, `frozen_replay_individual`에 보존했다.

모든 원본 및 개입 점은 유한하여 support는 각 쌍 안에서 변하지 않았다. KF32–35의 법선 절대 차이 p90은 원본 0.0951, A 제외 0.0439, B 제외 0.1327이다. 다른 쌍의 p90과 signed p10–p90, 각 pose의 모든 축 성분은 `world_pairs.csv`에 있다. 양쪽을 동시에 제외하면 KF32–35의 |normal| 중앙값은 0.0483이다. 각 KF의 영향을 별도로 보면 A 제외와 B 제외의 방향이 달라서, 양쪽 동시 제외만으로는 각 입력의 영향을 분리할 수 없다. 접선/XY도 함께 바뀐다.

KF36 pre에서 KF32–35의 |normal| 중앙값은 원본 0.0510, A 제외 0.0172, B 제외 0.0911이고 post에서는 각각 0.0679, 0.0137, 0.1073이다. 저장된 backend pose 변경과 첫 관측의 영향이 모두 이 조건부 수치에 나타나지만, 두 효과의 전체 시스템 인과 기여를 분리한 것은 아니다.

## 검증과 음성 대조

- 원본 replay는 23개 전후 XYZ 및 누적 confidence와 모두 bitwise 일치했다. 최종 world 후보와 E1 export 최대 거리는 1.95×10⁻⁷ 지도 단위다. KF별 ROI의 source pixel, 후보 pixel 및 전 단계 데이터 해시를 보존했다.
- E5에서 첫 입력의 저장 상대 Sim(3) 역변환과 E2 원본 cross 점의 최대 차이는 6.31×10⁻⁷ pair 단위로 확인했다. E4에서 Sim(3) round-trip과 world-preserving scale 재표현도 확인했다. 이 검증은 해당 ROI와 저장값에 한정된다.
- 합성 weighted fusion에서 단일 편향 입력의 효과와 편향이 없는 입력의 제거 결과를 확인했다. 합성 대조는 실제 장면의 정상 영역 대조를 대신하지 않는다.
- 독립 correspondence와 가시성이 검증된 seam-free 실제 ROI가 없어 실제 음성 대조는 `INSUFFICIENT_SUPPORT`다. E2a는 영상 추적 후보이며 올바른 대응이라는 독립 보증이 없다. 따라서 G2/G4를 충족했다고 판정하지 않는다. support를 0 오차로 채우지 않았다.

## 해석 및 다음 결정

첫 입력을 제외하면 frozen replay의 최종 ROI가 변하며, 선택된 후보의 분리는 어느 KF를 제외하는지에 따라 줄거나 늘었다. 이는 첫 관측의 **조건부 영향**을 확인한다. 감소한 분리가 실제 깊이 정확도 개선이라는 뜻은 아니며, 원래 fusion이 오류를 만들었다거나 다른 원인보다 우세하다는 결론도 지원하지 않는다. 독립 대응·가시성, 정상 영역, 외부 깊이 기준과 독립 시퀀스가 없다.

다음 단일 결정은 E7 일반화 판정에 앞서 **독립 영상 대응과 실제 seam-free 음성 대조 ROI를 확보·검증하여 G2/G4 support를 충족할 수 있는지 확인**하는 것이다. 실패하면 이 결과를 단일 구간 사례연구로 제한한다.
